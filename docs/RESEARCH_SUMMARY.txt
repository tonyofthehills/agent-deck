KEY FINDINGS:
=============

1. MONOREPO RECOMMENDED: YES
   - Best for mixed Swift/JavaScript projects
   - Enables code sharing, unified CI/CD, easier team onboarding
   - 2025 consensus across industry (Mercari, Matera, Twitter)

2. RECOMMENDED BUILD TOOL: pnpm
   - Fastest JavaScript monorepo manager (2025)
   - 80% less disk usage than npm via hard linking
   - Best monorepo support among all package managers
   - Fully compatible with Expo (SDK 52+)
   - Active community, production-proven

3. ARCHITECTURE: EMBEDDED PWA
   - Single PWA codebase serves 3 platforms:
     * Browser (dev)
     * Mobile via Expo
     * Mac via embedded WebRoot/
   - No code duplication, single source of truth
   - Vanilla JavaScript (no build step)

4. SWIFT CODE MANAGEMENT: Swift Package Manager
   - Local packages in Modules/ directory
   - Full Git history preservation possible
   - SPM is built into Swift, no CocoaPods needed

5. SHARED CODE STRATEGY:
   - JavaScript/TypeScript: pnpm packages/ (types, utils, config)
   - Swift: Separate per app (cannot be shared with JS)
   - Assets: Shared JSON files (icons, colors)
   - WebSocket client: Shared across mobile + embedded PWA
